Construiremos una plataforma profesional de simulación de exámenes ISTQB 🎯

El objetivo será crear una aplicación completa donde el usuario pueda:

✅ Resolver exámenes ISTQB simulados

✅ Elegir diferentes certificaciones ISTQB

✅ Generar automáticamente exámenes realistas

✅ Mostrar resultados, puntaje y respuestas correctas

✅ Simular tiempo real del examen

✅ Guardar progreso e historial

✅ Consumir preguntas desde una API REST

✅ Mostrar imágenes, diagramas, tablas y esquemas visuales

✅ Aleatorizar preguntas y respuestas automáticamente

✅ Generar exámenes balanceados según el syllabus oficial ISTQB

✅ Practicar por capítulos y learning objectives

✅ Reforzar preguntas incorrectas automáticamente

✅ Validar inteligentemente disponibilidad de preguntas

# 🚀 MODOS PROFESIONALES DE EXAMEN

La plataforma debe soportar los siguientes modos:

---

## ✅ EXAMEN OFICIAL ALEATORIO

Simula el examen oficial ISTQB.

Debe:

✅ generar exactamente 40 preguntas

✅ respetar la distribución interna del syllabus

✅ seleccionar preguntas aleatorias del banco

✅ mezclar preguntas

✅ mezclar respuestas

✅ generar un examen diferente en cada intento

---

## ✅ EXAMEN RÁPIDO

Modo rápido para práctica rápida.

Debe:

✅ generar 10 preguntas aleatorias

✅ seleccionar preguntas del banco de la certificación elegida

✅ mezclar preguntas

✅ mezclar respuestas

Objetivo:

✅ práctica rápida diaria

✅ micro sesiones de estudio

---

## ✅ EXAMEN POR CAPÍTULO

Permite practicar capítulos específicos.

El usuario podrá elegir:

✅ capítulo 1

✅ capítulo 2

✅ capítulo 3

etc.

El sistema debe:

✅ generar preguntas SOLO del capítulo seleccionado

✅ permitir elegir cantidad de preguntas

✅ mezclar preguntas y respuestas

Ejemplo:

{
"capitulo": "1",
"cantidad": 15
}

---

## ✅ EXAMEN POR LEARNING OBJECTIVE

Permite practicar objetivos específicos.

El usuario podrá seleccionar:

✅ FL-1.1.1

✅ FL-2.3.2

✅ ATM-3.2.1

etc.

El sistema debe:

✅ filtrar preguntas por learning objective

✅ permitir seleccionar varios objetivos

✅ generar examen personalizado

---

## ✅ EXAMEN DE REPASO

Debe generar un examen usando:

✅ preguntas respondidas incorrectamente anteriormente

Objetivo:

✅ reforzar debilidades

✅ mejorar aprendizaje

El backend debe:

1. leer historial del usuario

2. detectar preguntas falladas

3. generar examen basado en errores anteriores

4. mezclar preguntas y respuestas

---

## ✅ EXAMEN PERSONALIZADO

El usuario podrá construir su propio examen.

Debe permitir elegir:

✅ capítulos

✅ cantidad de preguntas

✅ learning objectives

✅ certificación

✅ incluir/excluir preguntas ya respondidas

✅ temporizador opcional

Ejemplo:

{
"certificacion": "Foundation",
"capitulos": ["1", "2"],
"cantidad": 25,
"learning_objectives": [
"FL-1.1.1",
"FL-2.3.2"
]
}
