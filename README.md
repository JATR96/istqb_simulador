# ISTQB Simulator

Plataforma profesional de simulación de exámenes ISTQB.

## Tecnologías

### Frontend
- React
- Vite
- Axios
- React Router

### Backend
- FastAPI
- SQLAlchemy
- MySQL
- Alembic

## Características

- Multi certificación
- Multiidioma
- Exámenes dinámicos
- Aleatorización automática
- Learning Objectives
- Distribución por syllabus
- Historial y estadísticas
